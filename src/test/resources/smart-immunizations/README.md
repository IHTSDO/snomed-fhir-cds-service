# WHO SMART Immunizations — test scenarios

Test scenarios for the WHO SMART content in `knowledge-bases/smart/immunizations-bcg/`.

`tests/IMMZD2DTBCG/` holds the patient bundles of the IG's Karate tests
(`input/testing/features/plandefinition/IMMZBCG/`, repository commit `bd7fa726706efc92d972d0dcebba9505f386b078`).
It also holds `expectations.json`, extracted from `IMMZD2DTBCG.feature`: the evaluation date and, for each
scenario, whether a medication proposal is expected and the expected guidance text.

Source: https://github.com/WorldHealthOrganization/smart-immunizations — licensed CC0-1.0.
